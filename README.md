#Seaway

##1. O que é o Projeto
Seaway é um sistema web desenvolvido para gerenciar os cadastros de clientes, fornecedores e produtos de uma vidraçaria. O objetivo principal é fornecer uma interface simples e eficiente para o controle operacional do negócio.

##2. Entidades do Sistema
O sistema é estruturado em torno de três classes principais de cadastro:
• Cliente: Responsável pelo armazenamento de dados como [ex:ID, nome, CPF, e-mail e telefone].
• Produto: Armazena as informações dos itens, incluindo [ex:ID,  nome, preço, descrição e quantidade].
• Fonrecedor: Respnsavel por trazer matéria prima para comércio [ex:ID, nome. CNPJ, Telefone, email].

##3. Tecnologias Utilizadas
A arquitetura do sistema foi construída utilizando as seguintes tecnologias:
• JSP (JavaServer Pages): Utilizado para a criação das páginas web dinâmicas e renderização da interface do usuário.
• JSON: Formato leve de troca de dados estruturados entre o front-end e o back-end.
• Gson: Biblioteca da Google utilizada para converter objetos Java em JSON e vice-versa de forma automatizada.
• Apache Tomcat: Servidor web e container de Servlets utilizado para hospedar e executar a aplicação localmente.
